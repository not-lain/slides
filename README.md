# slidev Slides

This repository contains my collection of slides created with [Slidev](https://sli.dev/).

## 🚀 Getting Started

### Prerequisites

Make sure you have [Node.js](https://nodejs.org/) and [`pnpm`](https://pnpm.io/) installed.

### Run Locally

1. **Clone the repository:**
   ```bash
   git clone https://github.com/not-lain/slides.git
   cd slides
   ```

2. **Navigate to a slide project:**
   ```bash
   cd vectors
   ```

3. **Install dependencies:**
   ```bash
   pnpm install
   ```

4. **Start the development server:**
   ```bash
   pnpm dev
   ```

The slides will be available at `http://localhost:3030`.
